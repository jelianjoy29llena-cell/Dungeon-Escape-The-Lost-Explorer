# Dungeon Escape — web port
Open the repository in VS Code, then open web-port/index.html with Live Server. No Flutter or Node installation required. Internet is needed on first load for Phaser 3.90.0 from jsDelivr. For Netlify import the web-version branch with publish directory web-port and no build command. For manual deploy drag web-port to Netlify Drop. Android: open deployed HTTPS site in Chrome and use Add to Home Screen. Original gameplay has only Level 1 wired; levels 2 and 3 remain locked. Original audio settings have no playback implementation. UI is adapted to HTML and Phaser, not pixel-identical. Original Flutter files remain untouched. Browser testing not performed.
